Australian Wine Forecasting

A statistical forecasting project exploring seasonal patterns in Australian wine sales through time series modeling, comparative model evaluation and an interactive forecasting application developed in R Shiny.

Time series analysis · Statistical modeling · Forecasting · Model validation · Application development

The challenge

Identify trends, seasonality and temporal dependencies to forecast Australian wine sales.

The approach

Compared seasonal ARIMA, ETS, time series regression, seasonal naïve and ensemble models. Investigated transformations, differencing, residual diagnostics and rolling-origin cross-validation.

Validation results

Earlier fortified-wine analysis (1994 validation): manual ARIMA RMSE 273.09, ETS 318.90, automatic ARIMA 328.50, time series regression 426.53. Manual ARIMA MAPE 9.16%; RMSE 16.9% lower than automatic ARIMA. These results are from the earlier analysis, not verified against the final Shiny app.

Outcome

Developed an interactive R Shiny application for model comparison and forecast visualization.

Skills demonstrated

Time series analysis · Statistical modeling · Forecasting · Model validation · Application development
